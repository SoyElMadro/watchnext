# [WatchNext](https://mdrwatchnext.netlify.app)

> Descubre tu próxima película o serie — interfaz ligera hecha con Vite + React (demo en Netlify).

---

## 🔎 Descripción
WatchNext es una pequeña web para descubrir películas y series. Permite buscar por título, ver detalles, calificar y guardar en listas personales. Ideal como proyecto para practicar consumo de APIs, React + Vite y Tailwind CSS.

**Demo (deploy):** https://mdrwatchnext.netlify.app

---

## 🚀 Características principales
- Búsqueda de películas/series.
- Página de detalle con fecha, sinopsis y puntuaciones.
- Guardado de items en listas (localStorage).
- Interfaz responsiva y animaciones sutiles.

---

## 🧰 Tecnologías
- JavaScript (ES6+) · React · Vite  
- Tailwind CSS  
- Consume la API de **TMDB** (The Movie Database)  
*(Revisá `package.json` para ver dependencias exactas y versiones.)*
